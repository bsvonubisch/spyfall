# Spyfall

A mobile-first HTML game inspired by Spyfall: ask questions, spot the spy, and keep the secret location hidden.

## Project status

This project is in early development. The repository currently contains this README; the playable game is still to be built. Features below describe the planned direction.

## The game

Players share a secret location, except for one player who is the spy. By asking and answering questions, the group tries to identify the spy while the spy tries to work out the location.

The experience will be designed for playing together in person, with a phone-friendly interface to guide each round.

## Planned first version

- Simple player setup and round controls.
- Random selection of a secret location and a spy.
- Private role reveals so each player sees only their own information.
- A round timer to keep the game moving.
- An end-of-round reveal and an easy way to play again.

Exact rules, player limits, and how devices are shared or connected will be decided during development.

## Design goals

- **Mobile first:** responsive layouts, readable text, and large touch targets.
- **Quick to start:** a lightweight browser experience with no app installation.
- **Easy to understand:** clear instructions and minimal setup.
- **Private reveals:** keep roles and the location hidden between turns.

## Technology

The planned foundation is HTML, CSS, and JavaScript. Frameworks, build tools, and hosting have not been selected yet.

## Running the game

There is no playable build yet. Setup and launch instructions will be added alongside the first implementation.
